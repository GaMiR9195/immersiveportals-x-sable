## Известный сбой исходного проекта

`tests/portal/run-detector-fixtures.sh` останавливается на assertion:
`26cm protrusion releases while most of cube still overlaps`.

`PortalCrossingDetector.java` и соответствующий test побайтно совпадают с предоставленным ZIP: этот геометрический сбой не внесён данным патчем. Порог/политика transit намеренно не менялись в задаче восстановления обычного мира. Это остаётся известным ограничением исходной ветки, а не зелёным портальным тестом.

Устаревшие GL fixtures обновлены под уже существовавшие интерфейсы production-кода; GL tests после этого проходят. Это исправление тестовых заглушек, не проверка Minecraft Mixin transformation.

## Обязательно проверить в игре

В этой среде не запускался полноценный клиент Minecraft с миром, графикой и вашим комплектом модов. Поэтому все пункты ниже остаются ручной матрицей, а не заявлением «идеально проверено».

Перед первым запуском — резервная копия мира. Установить полученный integration JAR **вместо** старого JAR этой же интеграции, а не рядом; Sable 2.0.6, Simulated/Aeronautics/Offroad и прочие зависимости остаются отдельными модами.

| Сценарий | Ожидаемое поведение |
| --- | --- |
| Iron Handle: новый/старый ship, начало/конец перетаскивания; несколько миров загружены, разный порядок их появления | Нет рывка к нулю/plot coordinates; joint не зависит от последнего pipeline |
| Два floating-material ships: вода/суша в одном мире; затем одинаковые координаты в другом мире | Вода действует только в фактическом parent; сравнить с upstream Sable по осадке/устойчивости |
| Rope ship↔ship, ship↔ground; длинная верёвка за пределами камеры | Видна из обычного parent, не требует входа в storage; без двойного рендера |
| Колёса: земля, вода, нагрузки; Swivel Bearing/другие joints | Силы, anchors и collision queries в правильном frame |
| Swivel Bearing: многократное создание/ломание, смена блока на том же месте, reload chunks, relog | Нет старых Flywheel instances/фантомной геометрии |
| Envelope + Hot Air Burner: объём, нагрев, изменение высоты; overworld/другая dimension | Давление соответствует фактическому миру и высоте; проверять полный газовый/кинетический цикл |
| Разные биомы: свежая сборка, rehome, сохранение/перезапуск | Исходный biome plot не сбрасывается на PLAINS |
| Creative Physics Staff lock/unlock двух ships в разных worlds | Иконка видна только в соответствующем parent; само состояние сохраняется |
| Частицы из BE/механизмов: plot-local и уже world-space emissions | Видны нужным игрокам, нет двойной трансформации/двойной скорости |
| Sodium + Iris/без shaderpack + Flywheel включён/выключен | Проверить обе ветки визуалов, освещение, тени и отсутствие дублирования |
| Портал: посмотреть через портал, straddle, parent flip, сломать объект во время portal pass | Не остаётся буферов/визуалов; storage identity не меняется; проверить существующий transit отдельно |
| Dedicated server + два клиента, unload/reload parent chunks, disconnect/reconnect | Нет утечки state, зависания teardown, пропавших packets |

Не реализована новая политика распределения fluid forces между сторонами портала. Не восстановлены уже утраченные biome keys старых сохранений. Произвольные моды, обходящие Sable API и напрямую читающие `level.dimension()`, не могут автоматически стать portal-aware от одного общего исправления.
