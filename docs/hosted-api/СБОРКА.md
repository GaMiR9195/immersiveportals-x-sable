# Сборка

Требуется JDK 21; Gradle wrapper включён. Sable dependency зафиксирована на 2.0.6.

Natives уже лежат в корне проекта; `processResources` кладёт их в `natives_ipl/` JAR. Не заменяйте их stock Rapier или DLL из старой версии Atlas: ABI 2 обязателен.

## Изменение нативного кода

Rustup toolchain: nightly-2026-02-01, pinned в `natives/rust-toolchain.toml`.

Linux x86_64:
```
cd natives
cargo test --workspace --lib
./build-linux.sh
```

Windows x86_64 GNU: `natives/build-windows.ps1`; он включает обязательную проверку/починку PE import descriptors и кладёт DLL в корень. Требуется GNU host/toolchain и описанные в скрипте rust-mingw/llvm-tools. Linux cross-build проверен с установленным MinGW GCC:
```
cd natives
CARGO_TARGET_X86_64_PC_WINDOWS_GNU_LINKER=x86_64-w64-mingw32-gcc cargo build --release -p sable_rapier --target x86_64-pc-windows-gnu
cp target/x86_64-pc-windows-gnu/release/sable_rapier.dll ../sable_rapier_x86_64_windows.dll
python3 fix_import_descriptors.py ../sable_rapier_x86_64_windows.dll
```

Выполненные release-builds использовали один job и тот же vendored engine. Две разные OS-библиотеки собираются отдельно; Windows DLL проверена статически, не запускалась в Linux.

## Java/JAR
```
./gradlew build --no-daemon --max-workers=1
```

Первичная подготовка Minecraft/NeoForm требовательна к памяти. В использованной Linux-среде декомпиляция прошла с `_JAVA_OPTIONS='-Xmx2600m -XX:ActiveProcessorCount=1'` и JDK 21; предыдущие 4G-child при лимите всей среды 4GiB и 1800m heap не подошли. На обычной машине с достаточной RAM эти ограничения не нужны.

Тесты fixtures запускаются через `tests/compat/run.sh`, `tests/native/run-abi.sh /absolute/path/to/library`, `tests/gl/run.sh`, `tests/portal/run.sh`, `tests/render/run.sh`. Установите `JAVA_HOME` в JDK 21. Для геометрии нужен JOML 1.10.5 из Minecraft Gradle cache или `JOML_JAR`.

Аудит ABI против фактической зависимости:
```
python3 tests/native/check-sable-abi.py /path/to/sable-sable_rapier-1.21.1-2.0.6.jar
```
