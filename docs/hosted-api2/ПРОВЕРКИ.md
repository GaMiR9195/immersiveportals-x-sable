# Проверки второго прохода

## Автоматически выполнено

- JDK 21; `./gradlew assemble`, затем `./gradlew build`: SUCCESS. Gradle `test/testJunit`: NO-SOURCE, это **не игровой GameTest suite**.
- 44 assertions новых fixtures на **production** callback context, spatial policy, read-scope, moving-link reconciliation, visual view context с маленькими fake-world/actor fixtures.
- 271 ASM/config assertions против байткода фактических зависимостей: разрешение всех production mixin config entries, существование методов, invoke descriptors и pre-entity tick seam.
- Настоящий Sponge Mixin + MixinExtras transformer применён к 22 реальным target-классам. Подключены исходные Sable/Flywheel mixins в проверяемых узлах и PYM overwrite из предоставленных исходников. Проверены injection counts/Local capture/WrapMethod signatures; не только поиск текста в файле. Это **изолированная трансформация**, не полный NeoForge launch и не игровая отрисовка.
- PYM `ScaleAwareBlockClip` и его BlockGetter overwrite отдельно скомпилированы из предоставленного source tree. Эти upstream classes не перепакованы в устанавливаемый мод.
- 14 прежних environment fixtures + common boundary links без client bridge классов.
- 40 program-bind fixtures; 27 render-cache checks; 7011 section/culling checks; 5523 portal-geometry checks.
- Реальная загрузка Linux native через JNI: ABI, voxel material/callback registration, rope create/query/remove/repeated teardown, scene disposal.
- Все 53 JNI декларации совпали с Sable 2.0.6. Native binaries не менялись с предыдущей поставки.

Minecraft 1.21.1; NeoForge 21.1.228; Sable 2.0.6; companion 1.6.0; Create 6.0.10-280; Flywheel runtime JAR 1.0.6; Veil 4.1.4; Sodium 0.8.12. Предоставленные Flywheel sources 1.0.5 использовались для чтения, сигнатуры проверялись по фактическому 1.0.6 JAR.

## Воспроизведение

JDK 21 и Gradle wrapper. Для fixtures:

```sh
bash tests/hosted-api2/run.sh
bash tests/compat/run.sh
bash tests/gl/run.sh
bash tests/render/run.sh
bash tests/portal/run.sh
bash tests/native/run-abi.sh "$PWD/sable_rapier_x86_64_linux.so"
```

Укажите `GRADLE_USER_HOME` или `JOML_JAR`/`ANNOTATIONS_JAR`, если зависимости не в обычном Gradle cache.

Трансформация actual dependency bytecode:

```sh
./gradlew assemble writeHostedApi2Classpath -I tests/hosted-api2/write-classpath.gradle
bash tests/hosted-api2/run-transform.sh
```

Для optional PYM проверки второй аргумент `run-transform.sh` — каталог с отдельно скомпилированными PYM классами. Без него optional PYM target отсутствует, как в игре без PYM. Harness resources не содержат игровой код upstream, только конфигурации; это тестовый service loader, он не входит в устанавливаемый JAR.

## Обязательная ручная матрица на копии мира

1. Обычный мир: маленькая и большая thruster-платформа, подъём/спуск 20/60/100+ блоков/с, стоящий и идущий игрок, вид сбоку; проверить отсутствие нарастающего отрыва deck/player.
2. Flywheel instancing/indirect/off: Swivel Bearing, Mechanical Press и произвольные другие BE; поставить, изменить blockstate, сломать, заменить в той же позиции, разобрать ship, relog. Не должно оставаться старых visuals.
3. Те же объекты с Sodium, Iris без shaderpack и с используемым shaderpack. Проверить lighting, normal matrix после scale и portal-view отдельно.
4. Два sub-level с Create Redstone Link и ground receiver: разные частоты; войти/выйти из радиуса; ground↔ship и ship↔ship. Другой parent dimension с той же частотой не должен получать сигнал.
5. Hose/Magnet именно Sable-варианта: зазор 1/3/4 блока, повороты и разные размеры. Требуется правильный адаптер, в предоставленных VS sources он не найден.
6. PYM/Pocket: scale 0.25/0.5/1/2/4, place/break/use с нескольких сторон, расстояние reach, пересборка, relog. Через портал — отдельный сценарий, не подтверждён данным harness.
7. Непостоянные листья, стекло, лёд: столкновения ниже/выше штатного порога. Persistent leaves отдельно как expected non-break.
8. Honey Glue и Create glue: assembly → движение → disassembly → save/reload; отдельно старая постройка и новая после обновления. Проверить shape/UUID/отсутствие дубликатов.
9. Create rotating/moving contraption на sub-level: Flywheel on/off, после late load, после disassembly; тот же тест для обычной наземной contraption как контроль.
10. Звуки и частицы: burner/exhaust, block break, collision sounds, custom addon effects, оба игрока в multiplayer. Проверить, что эффект не виден/не слышен только из storage dimension и не появляется дважды.
11. Контроль предыдущих исправлений: биомы, плавучие материалы, Envelope/Hot Air Burner, ropes и staff lock. Межизмерительный перенос/portal aperture — отдельная матрица, не основание считать обычный мир проверенным.

## Не выполнено здесь

Полный игровой клиент/сервер со всеми модами пользователя, shaderpacks/GPU rendering, Windows native runtime, тест тысячи разных модов, восстановление уже потерянных glue-данных. Нельзя считать эти проверки зелёными по успешному `build` или трансформации классов.
